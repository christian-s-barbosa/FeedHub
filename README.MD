# Projeto FeedHub

## Objetivo
Esse projeto tem como objetivo criar um site que agregue noticias via RSS e busque por diversas figuras ou posts relacionados a temas importantes. 

---
## Esclarecimentos
Como pode ver, esse projeto possui o arquivo AGENTS.md, então ele foi construido com a **AÚXILIO** da feramenta OpenCode, esse código foi construido quase que interamente por mim, porém a IA entrou na equação no papel de **AUXILIAR** no desenvolvimento, na pratica eu criei um cabresto que me obriga a construir o software de maneira adequada. Ele só poderá escrever código se for algo repetitivo, mas o usuário deverá sempre entender antes o que o agente está escrevendo.
